# 设备界面改版

2026-11-15 研究站、网络中心和计算机三个正式 Java 界面已按新预览实现：[研究站](previews/research-station.html)、[网络中心](previews/network-center.html)、[计算机](previews/computer.html)。预览按约 1.7 倍显示，下文坐标和尺寸均为游戏内 GUI 像素。

三个界面直接继承 `AEBaseGui`，不显示玩家背包，新增文案已加入对应 `LocalizationEnum` 与中英文语言文件。研究站容器通过 AE `GuiSync(4)` 同步队伍名称，用于标题副行；名称由 `ServerResearch.teamTitle` 在当前服务器会话中按研究站所有者的准确 FTB 队伍身份读取，队伍不存在时抛出异常，禁止在容器中自行解析队伍 ID；资源数值包与后台计算沿用现有实现。必须通过本地化枚举取得文案，禁止在 GUI 中拼接翻译键。

## 通用元素

三个界面共用包级 `DeviceGuiDraw` 绘制面板、状态标签、进度条、卡片、材料槽与对齐文字。文字一律按原字号绘制：超出宽度时截断并以省略号结尾，悬停时用 `DeviceGuiDraw.fits` 判断后显示完整文字，禁止缩小字号挤入。右对齐文字以实际宽度贴齐右边界。固定文案在界面初始化时缓存，数量和进度文本在对应同步值变化后更新。滚动列表统一使用 AE `Scrollbar.SMALL`，只在内容超出时显示，滚轮只在列表或滑块区域内生效。

配色沿用现有常量：底色 `0xcbccd4`，面板 `0x9a9fb4`，槽位与空条 `0xadb0c4`，亮边 `0xf2f2f2`，深色 `0x413f54`，分隔线 `0x696d88`，次要灰 `0x878fa5`，正文 `0x404040`。新增次要文字色 `0x5a5d72`，用于小标题右侧说明、单位和副标题。

状态标签高 10 像素，左侧 3×3 色块加文字，四周 1 像素描边。三种配色：正常为文字/色块 `0x1f6b2a`、底 `0xc2d4c5`、边 `0x8fb095`；等待为 `0x7a5200`、底 `0xddd2b6`、边 `0xb9a77a`；异常为 `0xa02020`、底 `0xdcc3c6`、边 `0xc09398`。状态标签固定在标题栏右侧，宽度按文字宽度计算，标题文字按剩余宽度截断。

进度条使用 `0xadb0c4` 底，填充默认 `0x413f54`；表示已完成或已满足时填充 `0x1f6b2a`，表示不足或用满时填充 `0xa02020`。行内细条直接绘制 2 像素底与填充，主进度条高 5 像素并使用 1 像素 `0x696d88` 描边。

列表行为面板内的卡片：底 `0xa3a7bb`，1 像素 `0x8d92a8` 描边，悬停底 `0xb6baca`，选中底 `0xf2f2f2` 并改用 `0x696d88` 描边。数值右对齐，名称左对齐并按剩余宽度截断，截断时悬停显示完整文字。

图标按钮使用 AE2S `SimpleIconButton`，研究队列的上移、下移分别使用 `Icon.ARROW_UP` 和 `Icon.ARROW_DOWN`；文字按钮继续使用 `AE2Button`。

## 研究站

尺寸保持 384×288。标题栏左侧为容器标题，副标题位置用次要文字色显示队伍名称；标题栏右侧不放内容。

顶部面板依次为 18×18 图标槽、研究名称、等级标签和状态标签。等级标签为 `0x696d88` 底、`0xf2f2f2` 文字的 `Lv.N`。名称下方一行用次要文字色显示“工作量 已累计 / T t · 参与研究站 N”，参与站数从原底部单独一行移到这里，底部那一行删除。面板最下方是横跨整个面板的主进度条，右侧显示百分比。状态标签映射：研究中为正常，等待条件和手动研究为等待，无访问权限为异常。没有当前研究时面板只居中显示一次“暂无研究”。

左侧面板先显示“材料”小标题，右侧说明为“当前可用 / 剩余需求”。材料固定五列，每格 32×30，使用 18×18 槽与 16×16 图标，数量文字位于图标正下方；当前可用小于剩余需求时数量为异常红色，悬停显示名称和完整数值。材料高度按格子行数计算。其后为“网络资源”小标题，右侧说明“占用 / 上限（/t）”。每项资源第一行为名称和占用/上限，第二行为累计细条，第三行为次要文字色的累计数值/总需求和百分比；累计完成后第一行数值改为“已完成”，细条为完成绿色。左侧可见高度为 180，超出时显示滑块并收窄列表，按滚动位置直接计算可见材料和资源索引；绘制和悬停共用同一套区段高度计算，空材料或空网络资源各占 14 像素提示行。

右侧面板标题为“研究队列”，右侧显示“数量 / 5”。每项为卡片行，依次是序号、名称、等级；队首卡片左侧有 2 像素完成绿色竖条，等级前加“进行中 · ”并使用完成绿色。按本次说明允许的方案省略队列图标列。底部按钮依次为上移图标按钮、下移图标按钮、设为当前、移出队列，四个按钮在队列面板内左对齐排列，启用条件沿用现有规则。无访问权限时顶部和队列都显示“无访问权限”。

实现位置为 `GuiResearchStation`，客户端在 `ResearchStationClientView` 缓存材料简写、网络资源百分比和队列等级文字。`ResearchStationPacket.QueueEntry` 保持原字段。新增文案“工作量”“进行中”“已完成”。

## 网络中心

宽度 384，高度继续随资源行数在 162～242 之间变化，超过 5 行启用本地滑块。

标题栏左侧为容器标题，右侧为状态标签。网络已生效为正常；备用中心、暂无可用中心为等待；结构未成型、所有者队伍无效、中心能源不足、中心等级不足、并发额度不足、网络状态未就绪为异常。悬停状态标签时沿用现有提示，能源不足仍附加供能提示。

顶部面板左侧为深色数字框：`0x413f54` 底，等级用 `0xcfe3ff` 显示两位数字，未生效时显示“—”并改用次要灰；数字框下方为“网络等级”。右侧第一行左为“并发占用”，右为“占用 / 总数”；第二行为 16 格分段条，每格按占用比例填充，最后一格允许部分填充；第三行左为“每格 N”，右为“可用 N”。

资源面板小标题为“资源供给”，右侧说明“占用 / 产出”。每行名称居左、占用/产出居右，下方为 2 像素利用率细条；占用达到产出时细条为异常红色，悬停显示完整名称与数值。`BASE_HEIGHT=132`、`ROW_HEIGHT=22`，最多显示五行，高度范围为 162～242，一行时保持最低高度 162。行数变化导致高度改变时重新执行 `initGui`，使界面重新居中并同步移动 AE 控件；超过五行时显示 AE 滑块。

实现位置为 `GuiNetworkCenter`。资源名称和数值已分别由 `NetworkCenterResourceView.Row.name()` 与 `amountsText()` 提供，不需要修改同步。新增文案“每格 %s”“占用 / 产出”。

## 计算机

尺寸保持 384×242。标题栏左侧为容器标题，副标题位置显示结构成型状态；右侧为状态标签。运行中为正常，配方等待、备用中心和暂无可用中心为等待，组件供给停止及其余网络状态异常为异常。组件资源不足或能源不足时，标题栏下方出现一条异常配色的提示条，左侧使用 AE `Icon.INVALID` 图标，文字为现有不足原因；正常时不占位。

提示条下方为三张数据卡：并发供给、已安装组件、FE 实耗/需求。数据卡小字标题使用次要文字色，数值使用正文色；FE 实耗低于需求时数值为异常红色。

数据卡下方为贴在面板顶部的两个页签“概览”“组件”，替换原来两个整宽 `AE2Button`。选中页签使用面板底色并与面板相连，未选中页签使用槽位底色。页签、滚动条和点击区域在提示条出现或消失时随数据卡一起移动。

概览页分左右两栏，中间 1 像素分隔线。左栏“组件所需资源”，右侧说明“可用 / 需求（/t）”；每项资源与“FE 实耗 / 需求”各占一行并带满足度细条，满足为完成绿色，不足为异常红色，“可用 FE”一行不带细条。右栏“对外资源供给”，标题右侧为单位“/t”（`ComputerGuiText.PerTick`），每行名称居左、数值居右。

组件页表头为空列、组件、数量、并发、FE/t、状态。每行为卡片：物品图标、名称、`×数量`、并发合计、FE 合计和状态标签（运行为正常，暂停为异常）。选中行使用选中卡片样式，底部固定两行显示“每件需求”“每件提供”。超过可见行数时继续使用现有滚动条。

实现位置为 `GuiComputer`。组件图标使用 `ComputerDetailsPacket.Component.item()` 绘制，不需要修改同步。“结构已成型”沿用 `MachineGuiText.Formed`，不足原因沿用 `ComputerGuiText.ResourceShortage` 与 `EnergyShortage`。
