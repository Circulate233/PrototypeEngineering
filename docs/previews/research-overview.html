研究总览
编辑模式：点击研究直接完成下一级
ESC
  • 全屏界面。滚轮以光标为中心缩放（50%～200%），按住左键在画布任意位置拖动平移；点击空白处或按 ESC 收起右侧详情，再按 ESC 关闭界面。
  • 研究平时只显示方块和图标；正在研究或保留部分进度的研究，方块右侧显示百分比。点击后展开为长框，显示名称、等级状态和进度条，同时在右侧弹出详情。
  • 左上角显示研究队列和当前研究：研究站研究显示工作量、材料“当前可用 / 剩余需求”和网络资源累计；手动研究显示投料玩家、材料“已投入 / 需求”和“消耗背包中的物品”。
  • “运行测试”页使用仓库示例脚本与 Java 示例的研究、材料、网络资源和奖励（自动布局）；“示例扩展”页为演示多前置、跨页前置、互斥与手动布局的虚构内容。
  • 玩家模式：前置未完成的研究点击无反馈，悬停列出还需完成的研究；按钮不可用时悬停显示原因。下载到数据库不会重复，队伍任一数据库已存等级不低于队伍等级时提示“已下载到 …”。
  • 数据库模式：只能选择本数据库已存的研究（数据库与物品）或队伍直属已完成的研究（仅物品），其余研究变暗且点击无反馈。
  • 编辑模式：由命令打开。点击研究直接完成下一级，缺少的前置研究同时补到所需等级；特殊研究写入当前活动数据库。开启“手动布局”后可拖动研究，“导出”覆盖该页的分页文件。
  • 研究名称、简介、图标和奖励组文字来自客户端研究内容 JSON；分页 ID 为研究命名空间，分页名称读取自动生成的本地化键。
