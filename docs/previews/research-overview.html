研究总览预览
  • 全屏界面，沿用 AE 配色与四角闭合的原生窗口贴图，游戏中隐藏 JEI 覆盖层。滚轮以光标为中心缩放（50%～200%），按住左键在画布任意位置拖动平移；点击空白处或按 ESC 收起右侧详情，再按 ESC 关闭界面。
  • 研究平时只显示方块和图标；正在研究或保留部分进度的研究，方块右侧显示百分比。点击后展开为长框，显示名称、状态和进度条，同时在右侧弹出详情；手动布局直接使用保存坐标，连线随坐标变化。
  • 左上角为分页、研究队列和当前研究；队列为空时不显示研究状态面板。研究站研究沿用正式研究站的标题、右对齐数值和累计条风格，材料每种一行显示“剩余可用 / 剩余需消耗”；手动研究显示投料玩家、材料“剩余可用 / 剩余需消耗”和“消耗背包中的物品”。两种材料的可用数量均以剩余需消耗数量封顶。
  • 右上角按“数据库：”、各阶级“LvN 已存条目 / 总容量”、“网络中心：LvN”、“最高研究站：LvN”分行显示本队设备信息；同阶全部已加载有效物理数据库合并计数。左下角没有缩放比例或操作提示。库不注册打开按键和物品，测试 mod 提供打开按键，实际入口由开发者调用打开方法。
  • “运行测试”页使用仓库示例脚本与 Java 示例的研究、材料、网络资源和奖励（自动布局）；其中手动、互斥、网络、持续和特殊研究五项需要标准 CT 测试入口，其余五项始终由 Java 注册。“示例扩展”页的 14 项研究也已在示例 mod 注册，展示多前置、跨页前置、互斥与手动布局；连同研究万花筒六项，无 CT 时共有 25 项，标准 CT 入口为 30 项。
  • 玩家模式：前置未完成的研究点击无反馈，悬停列出还需完成的研究；开始条件正文只显示网络中心与研究站，不重复显示活动数据库需求。操作由服务端判定，不可用按钮悬停说明缺少条件；下载到数据库按实际数据库的阶级和容量判断。下载到数据库不会重复，队伍任一数据库已存等级不低于队伍等级时提示“已下载到 …”。
  • 遗忘：详情底部的“遗忘个人等级”只移除自己的个人等级（可选择从哪一级起遗忘），队伍等级按全体成员重新计算；前置因此不足的研究会一并回退，并提示受影响的研究与队列条目。仅物品研究和特殊研究不能个人遗忘。
  • 数据库模式用于选择下载到物品的研究：任意队伍已完成、研究阶级不高于本数据库阶级的研究都可以选择，不要求已存于本数据库；特殊研究、未完成或阶级过高的研究变暗且点击无反馈，悬停说明原因。
  • 正式游戏的编辑模式由命令打开。所有研究都可以点击打开详情，详情中的“开始研究”立即完成下一级，缺少的前置研究同时补齐，特殊研究的按钮为“写入数据库”。长按研究约 0.3 秒后可自由拖动，松开后记录像素坐标，该页随之改为手动布局；“导出”覆盖该页的分页文件。右键画布空白处可添加分页或把已注册研究加入当前页，右键研究可编辑基础内容 JSON 和语言覆盖文件。此 HTML 演示研究操作、自由拖动和分页 JSON 生成，右键菜单与内容编辑窗口请在正式游戏中使用。
  • 研究名称、简介、图标和奖励组文字来自客户端研究内容 JSON。分页可通过 researches 显式列出完整研究 ID，positions 同样使用完整 ID；未指定 researches 时按分页 ID 对应的研究命名空间归组。分页名称可直接指定 title，未指定时读取自动生成的本地化键。此预览的“导出”生成可复制保存的 JSON。
