# 仓室美术来源

当前四种仓室使用 `F:/clone/PrototypeMachinery/src/main/resources/assets/prototypemachinery` 中第一级仓室资源：

- 输入、输出：`models/block/mix_hatch/input/lv1.json`、`output/lv1.json` 指向的 base 底图和输入/输出标记。
- 混合：`models/block/mix_hatch/io/lv1.json` 对应的三面纹理。
- 能源：`models/block/energy_hatch/input/lv1.json` 指向的能源底图和输入标记。

原模型的美术署名为 **WI_8614_ice**，X：`@wi8614ice`、`@wi8614art`。本项目保留署名，将底图与标记合成为静态纹理，使用普通 cube_bottom_top 模型，不复制 Bloom 管线。

PM 仓库附带的 [许可证](licenses/PrototypeMachinery-LICENSE) 同时收入产物的 `META-INF/licenses/PrototypeMachinery-LICENSE`。当前复用基于用户允许使用旧 PM/PN 资源的任务授权，未将美术标记为本项目重新创作。
