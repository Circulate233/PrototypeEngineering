# 研究总览界面与客户端研究内容

2026-11-16 研究总览只有 HTML 预览（[research-overview.html](previews/research-overview.html)），正式 Java 界面、客户端内容加载、图标解析注册和编辑命令都未实现。本文记录已确认的界面行为和后续实现规则，数据库界面中的“选择研究”入口按本文接入。

## 两种构造

研究总览是一个界面类，提供两个构造函数，两者共用画布、分页、节点和右侧详情，按构造参数切换可用操作。

使用玩家构造时用于研究。界面显示本队全部研究的完成情况和研究队列，玩家可以开始研究、调整队列、领取奖励，并把已完成的研究下载到当前活动数据库。使用数据库接口构造时只用于为研究下载选择目标，入口是数据库界面的“选择研究”按钮，选定后返回数据库界面；该模式不显示研究队列，也不提供研究或下载到数据库的按钮。

数据库模式只能选择已有的研究：`DATABASE_AND_ITEM` 研究必须已存于打开界面的这台数据库，按已存等级下载；`ITEM_ONLY` 研究按队伍直属等级，直属等级为 0 时不可选；`specialOnly` 研究不能作为普通下载目标。不可选的研究变暗，点击没有反馈，悬停说明原因。

## 全屏布局与画布

研究总览是全屏界面，画布铺满整个屏幕，没有外框窗口，所有面板直接悬浮在画布上。配色只使用 AE 界面已有的颜色：画布为 AE 面板色 `#9a9fb4` 加浅色网格线，悬浮面板为 AE 底色 `#cbccd4` 并使用 AE 窗口边框贴图，槽位 `#adb0c4`，深色强调 `#413f54`，状态色使用研究站与数据库已有的绿、黄、红三组标签色，按钮使用 AE 原生按钮与方形图标按钮贴图。禁止使用深色背景主题或参考图中的橙色、青色等非 AE 颜色。

各区域位置如下：
- 左上角：分页、研究队列和当前研究（见下文）。
- 顶部中央：斜纹提示条，玩家模式显示“队名 · 研究总览”，数据库模式显示“数据库名 · 选择下载研究”，编辑模式改为黄色并说明编辑操作。
- 右上角：玩家模式为状态面板，列出活动数据库名称、阶级与已存数量、网络中心等级和最高研究站等级，没有活动数据库时显示红色“无”；数据库模式为 AE `Icon.BACK` 返回按钮；编辑模式在状态面板上方显示当前分页的布局方式和“导出”按钮。
- 左下角：缩放比例和操作提示。
- 右下角：ESC 的当前作用。

右侧详情打开时，右上角和右下角内容随之左移，不被详情遮住。

预览按约 1.7 倍显示。游戏内尺寸以 GUI 像素计：节点方块 26×26（16×16 图标），带百分比的节点宽 50，展开长框 76×32，网格列距 92、行距 40，前置连线在目标列左侧 8 像素处折向；左上角区域宽 180，右侧详情面板宽 200。展开长框必须在下一列连线折点之前结束，高度不超过行距，展开时禁止覆盖其他研究或连线折点；调整尺寸时按此约束同步修改列距与长框宽度，禁止只加宽长框。

滚轮以光标位置为中心缩放，范围 50%～200%；按住左键在画布任意位置拖动平移，拖动距离超过 3 像素后不再触发点击。点击空白处收起右侧详情；ESC 先收起详情，没有详情时关闭界面，数据库模式下关闭即返回数据库界面。

## 研究节点

研究平时只显示方块和图标。方块颜色表示状态：已完成为绿底绿框，部分等级完成为绿底浅绿框，可研究为槽位色，当前研究为白底深色框，前置未完成为灰色并降低图标透明度，互斥阻止为红底红框，特殊研究为黄底黄框。多等级研究在右下角显示“当前等级/最高等级”，无限等级只显示当前等级。队列中的研究左上角显示队列序号，已下载到任一数据库的研究右上角显示黄色小方块。

当前研究和保留部分进度的研究，方块向右加宽，在图标右侧显示百分比。点击研究后节点向右展开为长框，显示名称和一行状态（多等级且未完成的研究显示“Lv.当前 / 最高”，其余显示状态文字）；带进度的研究额外显示进度条。名称超出长框时按原字号截断加省略号，完整名称在悬停提示和右侧详情中显示。同一时间只展开一个节点，再次点击或点击空白处收起。展开的长框被左上角面板或右侧详情遮住时，画布平移到刚好露出长框。

前置关系以折线连接：前置已满足为深色实线，未满足为浅色实线。跨分页的前置在研究左侧画一段虚线和空心圆点，悬停研究时在“还需完成”中写出所在分页名称。

## 左上角分页、队列与当前研究

分页紧贴屏幕顶边，从左上角开始横向排列。每个分页是固定宽度的标签：顶部一条贴住屏幕上沿的横条，横条下方居中显示大号分页名称，不显示图标或数量。当前分页的横条和文字为深色 `#413f54`，标签内有由上向下渐隐的浅色底；其他分页的横条为 `#878fa5`，文字为浅色，悬停时加深。名称超出标签宽度时按原字号截断加省略号；悬停显示完整名称和本页完成数（数据库模式为可选数量），编辑模式额外显示分页 ID 和名称键。分页超过顶部中央提示条左侧的可用宽度时换到下一行，左上角其余内容随之下移。

玩家模式在分页下方显示 5 个圆形队列槽，右上角标注序号，队首槽外圈按进度填充。点击任一队列槽切换到对应分页，把该研究移到画布中央并打开详情。队列槽下方是当前研究面板。数据库模式在分页下方显示数据库阶级、已存数量和可选研究规则，不显示队列。

队首为研究站研究时，当前研究面板显示研究名称、目标等级、参与研究站数、工作量进度条，材料逐行显示图标、名称和“当前可用 / 剩余需求”（规则同研究站界面），网络资源逐行显示“已累计 / 总需求”和累计条。队首为手动研究时显示投料玩家、研究时间进度、材料“已投入 / 需求”，以及“消耗背包中的物品”复选框：勾选表示由当前玩家接管投料，取消勾选暂停投料并保留已投入的材料与进度。投料玩家背包中缺少的材料数字显示为红色。

## 右侧详情

点击研究后右侧弹出竖向详情面板，贴住屏幕右边缘，高度占满屏幕。面板顶部为图标槽、研究名称、状态标签、等级标签和 AE 方形关闭按钮。正文依次显示研究简介与说明文字（来自客户端研究内容）、当前目标等级的研究进度、研究信息（目标等级、研究阶级、研究时间、下载方式）、前置研究、互斥研究、目标等级的材料与网络资源，以及完成奖励。已达最高等级的普通研究不再显示材料与网络资源。

完成奖励显示已完成等级和下一级的奖励组。每组显示标题、物品槽和说明文字；同一等级有多组时标注“任选其一”，未领取时点击奖励组选中，选中后才可领取。已完成未领取的等级显示“领取奖励”按钮，已领取显示绿色“已领取”，未完成显示“完成后可领取”。

研究、下载等操作按钮固定在面板底部。玩家模式下，不在队列中的研究显示“开始研究”（有保留进度时为“继续研究”）与“下载到数据库”；队首研究显示“移出队列”；队列中其他研究显示“设为当前”和“移出队列”。按钮下方一行显示下载状态。数据库模式只有“选择此研究”。

## 点击与悬停规则

玩家模式下，前置未完成的研究点击没有任何反馈，不展开节点也不打开详情；悬停时列出还需完成的研究及等级。其余研究点击后展开并打开详情，包括已完成、互斥阻止和特殊研究，以便查看文字与奖励。

条件不满足的按钮显示为禁用状态，悬停在按钮上显示原因。“开始研究”的原因按服务器入队判定给出：互斥研究已完成、研究队列已满、没有可用网络中心、活动数据库阶级不足、研究站等级不足、已达最高等级、特殊研究不能入队；开始条件回调由服务器在点击时执行，界面不预先调用。“下载到数据库”的原因按数据库写入判定给出：尚未完成、只能下载到物品、特殊研究、没有活动数据库、数据库阶级不足、容量已满、与数据库中的研究互斥。

下载到数据库不会重复。队伍任一数据库（含非活动数据库）的已存等级不低于队伍当前等级时，按钮禁用并显示“已下载到 数据库名（Lv.N）”；队伍当前等级高于所有数据库的已存等级时可以下载，写入活动数据库并更新已存等级，此时不显示已下载提示。界面显示的数据库列表和已存等级由服务器按队伍捕获后发送，客户端不自行查找数据库。

## 编辑模式

编辑模式通过服务器命令打开，只允许服务器管理员使用，界面与玩家模式相同，顶部提示条改为黄色。

编辑模式下点击研究方块的效果与玩家模式相同，只展开节点并打开右侧详情，不修改研究；区别是前置未完成的研究也可以点击打开。研究由详情底部的研究按钮执行：按钮仍为“开始研究”，点击后立即完成下一级，不进入队列，无视前置、互斥、权限、材料、研究时间与开始条件；已达最高等级时按钮禁用。特殊研究的按钮为“写入数据库”，点击后写入当前活动数据库并加 1 级，没有活动数据库、容量已满或已达最高等级时按钮禁用，悬停说明原因。

有效等级计算会把前置未满足的研究按阶段回退到 0，所以立即完成时缺少的前置研究必须同时补到所需等级，否则完成后的研究仍显示为未完成。完成结果与正常完成一致：按研究的下载策略提升成员个人等级或队伍直属等级，并为新完成的每一级创建奖励领取资格；队列中目标等级不高于新等级的条目移出。服务器收到请求后必须重新确认命令授权，再通过完成传播（`TeamResearchCompletion`）写入并保存；禁止在客户端修改等级。管理员设置等级（`requestAdminTeamLevel` / `requestAdminPlayerLevel`）不创建领取资格，不能直接用于编辑模式。

编辑模式下长按研究方块约 0.3 秒进入拖动，不需要先开启任何开关；按下后 0.3 秒内移动超过 3 像素按平移画布处理。拖动时研究跟随光标，松开时吸附到最近的网格并自动记录新坐标；目标格已有研究时取消本次移动，研究回到原位并提示。自动布局的分页在第一次拖动时改为手动布局，以当时自动布局的全部位置作为初始坐标，再写入被拖动研究的新位置。右上角显示当前分页是自动布局还是手动布局。

记录的坐标保存在客户端内存中，“导出”把当前分页的设置写回该分页文件并直接覆盖，写入失败时记录错误日志并在界面提示，禁止写入其他路径。详情的研究信息中额外显示研究 ID 和当前坐标。

## 客户端研究内容与分页文件

研究注册只包含服务端数据：Java 与 ZS 只注册研究 ID、等级、阶段、前置、互斥、材料、网络资源、奖励与下载策略等数据，不处理名称、简介、图标、分页和布局。研究名称、简介、说明文字、图标、奖励组文字、分页设置和布局全部由客户端 JSON 提供。现有 `ResearchDefinition.displayName`、`icon` 与 ZS `display(...)`，以及 `RewardGroup` 的 `title`、`description` 属于客户端显示数据，按本规则迁出；迁移在实现研究总览时进行。

内容根目录为 `config/prototype_eng/research_content/`。研究内容基础文件位于 `data/<命名空间>/<研究路径>.json`，语言覆盖文件位于 `<语言代码>/<命名空间>/<研究路径>.json`，例如 `zh_cn/pe_run_tests/research_station.json`。读取时先加载 `data` 下的基础文件，再用当前语言目录下同名文件中出现的字段覆盖对应字段；找不到语言文件属于正常情况，直接使用基础文件，不记录警告或错误。基础文件缺失时研究显示 ID 作为名称并记录一次警告。现有 `ResearchContentLoader` 按语言目录和 `en_us` 回退读取、缺失时记录警告，按本规则改写。

分页 ID 等于研究 ID 的命名空间，每个命名空间对应一个分页。分页文件为 `data/<命名空间>.json`，与同名命名空间目录并列，不会与研究路径冲突。分页名称使用自动生成的本地化键 `gui.prototype_eng.research_page.<命名空间>`，分页文件不写名称。分页文件字段如下：

```json
{
  "order": 10,
  "layout": "manual",
  "positions": {
    "basic_circuit": [0, 2],
    "data_storage": [1, 1]
  }
}
```

`order` 决定分页顺序，缺省为 0，相同时按命名空间排序。`layout` 为 `auto` 或 `manual`，缺省为 `auto`，编辑模式下拖动研究后自动改为 `manual`。`positions` 只在手动布局时读取，键为研究路径，值为 `[列, 行]` 网格坐标；手动布局中缺少坐标的研究按自动布局规则放到已有坐标的最大行之后。分页文件不存在时该分页使用默认值和自动布局。编辑模式导出用当前的 `order`、`layout` 和全部研究坐标覆盖此文件。

自动布局按同页前置关系计算列：没有同页前置的研究位于第 0 列，其余研究位于同页前置最大列加 1。同列研究优先放在其前置所在行，冲突时下移。没有任何同页前置关系、也不被同页研究依赖的研究，排在前置树下方空一行后，每行最多 6 个。跨页前置不参与列计算。

## 图标解析注册

图标 JSON 为 `{"kind": ..., "id": ..., "meta": ...}`，`kind` 决定解析方式，解析规则通过注册提供。内置两种：`item` 把 `id` 和 `meta` 解析为 `AEItemKey`，`icon` 把 `id` 按 `Icon.byId` 解析为 AE `Icon`。使用方可以注册新的 `kind`，注册时提供从 JSON 对象到可绘制图标的解析方法；未注册的 `kind` 在加载时报错并记录文件路径。研究图标与后续客户端内容共用同一注册表。

当前 `ResearchContentLoader` 只识别 `item` 和 `icon` 两个固定值并保存原始 ID，图标注册表尚未实现，本轮只记录规则。

## 与现有实现的关系

研究队列、开始研究、手动投料接管与暂停、奖励领取、数据库下载和管理员设置等级均已有服务器后台，研究总览只新增界面、容器和同步数据。需要新增的服务器部分包括：玩家模式的总览数据捕获（各研究等级、队列、当前研究进度与材料、奖励领取状态、队伍全部数据库的已存等级）、数据库模式的可选研究捕获、编辑命令及其授权、分页文件导出的客户端写入。数据库界面的“选择研究”按钮目前点击无操作并保留 TODO，接入本界面后移除。
